`plan.md` 및 `specs/*.md`의 인라인 주석 `[//]: # (...)` 을 스캔하여 피드백을 반영한다.

## spec 대상 지정

- `plan` → `plan.md`
- `001` → `specs/001/spec.md` 전체
- `001/1`, `001/task/1`, `001/task-001` → spec-001의 태스크 (1)
  - `specs/001/task-001.md` 가 있으면 해당 파일 사용
  - 없으면 `specs/001/spec.md` 의 태스크 (1) 항목만 대상
- `002/feed-001`, `002/feed/1` → `specs/002/feed-001.md`
- 인수 없음 → `plan.md` + `specs/**/*.md` 전체 대상

## 실행 규칙

- 반영 후 주석은 삭제
- 확신이 75% 미만이면 반영 전에 되묻기, 이상이면 바로 반영
